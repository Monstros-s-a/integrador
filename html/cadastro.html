Para que serve CSS?

Para que serve o CSS? • Definir cores e tipografia: Alterar cores de fundo, cores de textos, tipos de fontes, tamanhos e espaçamentos. • Controlar o layout: Organizar a posição dos elementos na tela usando ferramentas modernas como Flexbox e Grid. • Criar responsividade: Adaptar o visual do site para diferentes tamanhos de tela (como celulares, tablets e computadores) através das Media Queries. • Adicionar animações e efeitos: Criar transições suaves e interações visuais (como mudar a cor de um botão quando o cursor passa por cima).
