Sobre o projeto

Projeto Integrador · Curso Técnico · Senac Largo Treze

Problema

Estabelecimentos descartam alimentos próprios para consumo por falta de um canal simples para doá-los, enquanto muitas pessoas não têm acesso a alimentação adequada.

Objetivos

 

Objetivo geral

Desenvolver uma plataforma web que conecte estabelecimentos com excedente de alimentos a pessoas interessadas em retirá-los.

Objetivos específicos

  • Permitir o cadastro de doações com validação de dados;
  • Listar ofertas com busca, filtro e ordenação;
  • Permitir reserva com controle de estoque;
  • Oferecer interface responsiva com modo escuro.

Evoluções previstas para uma versão com back-end.

  • API e banco de dados para compartilhar as doações entre usuários;
